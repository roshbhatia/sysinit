# Technical documents

Choose the document by the decision that remains open.

| Decision | Structure |
| --- | --- |
| Whether to proceed, or which option to choose | [RFC](references/rfc.md) |
| How to implement an agreed decision | [Design document](references/design.md) |

Read the selected structure and apply the [document voice](references/voice.md)
when writing on the user's behalf. Pair outcomes with their acceptance evidence.

For local drafts, use `.sysinit/rfc-<slug>.md` or `.sysinit/design-<slug>.md`.
For work, use the private Notion draft workflow when available. Confirm the
destination before writing outward-facing material.
